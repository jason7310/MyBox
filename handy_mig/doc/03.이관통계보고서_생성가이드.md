# [핸디 10.x] 이관결과 보고서용 4대 종합 통계 생성 가이드

## 1. 개요 및 목적
- **목적**: ACUBE 원천 시스템에서 핸디 그룹웨어(V10)로 이관된 전자결재, 조직도, 기록물철, 첨부파일 전체 데이터에 대하여 발주처(한국보훈복지의료공단), 감리단, 운영팀 제출용 **이관결과 보고서 4대 종합 통계표**를 원클릭으로 자동 생성합니다.
- **핵심 특징**:
  1. **가변 연도 매개변수 지원**: 2016년 ~ 2026년(기본값)을 포함하여 2004년 ~ 2024년 등 원하는 연도 구간을 자유롭게 지정.
  2. **연월별 피벗 매트릭스 (1~12월 x 연도)**: 가로축 연도, 세로축 1~12월, 하단 건수, 총건수 서식 완벽 구현.
  3. **AS-IS vs TO-BE 1:1 무결성 인증**: 원천 대비 오차(Diff = 0) 검증서 자동 생성.
  4. **다각도 집계 현황**:
     - 소속 기관(지사)별 이관 건수 (본부, 중앙보훈병원, 부산/광주/대구/대전/인천보훈병원, 보훈요양원 등)
     - 기록물철 편철율(%) 및 단위업무 현황
     - 본문/첨부파일 스토리지 물리 통계 (수량, 용량 GB, 확장자 분포)
  5. **다중 출력 포맷**:
     - 엑셀 즉시 열람 CSV (UTF-8 BOM 포함)
     - 프리미엄 HTML 대시보드 (브라우저 열람, PDF 저장 및 인쇄 최적화 서식)
     - 터미널 콘솔 ASCII 테이블 즉시 미리보기

---

## 2. 실행 명령어 (SOP)

이관 서버의 마이그레이션 디렉토리(`handy_mig`)에서 다음 명령어를 실행합니다:

```bash
cd /app/handy_mig

# 1. 기본 실행 (2016년 ~ 2026년 전체 자동 집계)
./build_and_run.sh report

# 2. 연도 범위 명시적 지정 실행 (예: 2016년 ~ 2026년)
./build_and_run.sh report 2016 2026

# 3. 과거 전체 연도 지정 실행 (예: 2004년 ~ 2024년)
./build_and_run.sh report 2004 2024

# 4. 고급 옵션 (TO-BE 단독 조회 및 출력 디렉토리 지정)
# 문법: ./build_and_run.sh report [시작년도] [종료년도] [both|tobe|asis] [출력경로]
./build_and_run.sh report 2016 2026 tobe output/report
```
