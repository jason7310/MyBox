 2. 상세 작업 수행 내역 (Detailed Activities)
----------------------------------------------------------------------------------------------------

 [작업 1] 원천 데이터(ACUBE) 및 타겟(Handy 10.x) 데이터 모델 분석
   - ACUBE 전자결재/게시판/조직도 테이블 구조 분석
     * 대상 문서: 'DD05.테이블정의서_02.전자결재_V1.0.docx', 'DD05.테이블정의서(GW)_v1.0.xlsx'
     * 분석 대상: 결재문서(APPROVAL), 시행발송(SEND), 결재선(PARTICIPANT), 이력흐름(FLOW), 파일(DOCUMENT/DOCMBR)
   - ACUBE 원천 테이블과 Handy 타겟 테이블 간 매핑 정의서 및 컬럼 매핑 규칙 목록화
   - 대용량 결재문서(수백만 건)의 이관 시 성능 병목 요인(외래키, 인덱스, 대용량 LOB/첨부) 사전 도출

 [작업 2] handy_mig 프로젝트 인프라 및 설정 모듈 구축
   - 마이그레이션 전용 작업 공간 handy_mig/ 구조화:
     * handy_mig/config/ : 접속 및 운영 환경 설정
     * handy_mig/java/   : 순수 Java SE 17 기반 실행기 및 도구
     * handy_mig/sql/    : 마이그레이션 SQL 스크립트
     * handy_mig/lib/    : Tibero 7 공식 JDBC 드라이버 배치
   - config/db.properties 생성:
     * Tibero 7 TAC 접속 URL, 계정(INTRAWARE), 비밀번호 정의
     * 대용량 고속 처리를 위한 병렬도(parallel.degree=16) 기본값 설정
     * 스토리지 마운트 베이스 경로(storage.base.path) 정의
   - java/com/handy/mig/DbConfig.java 개발:
     * 외부 properties 파일 동적 로드 및 Connection Pool/환경변수 싱글톤 클래스 작성

 [작업 3] 핵심 마이그레이션 SQL 스크립트 초안 설계
   - sql/01.MAPPING_KEY_TABLE_CREATE.sql:
     * AS-IS 원천 키(DOC_ID)와 TO-BE 타겟 키(APPRID)를 1:1로 초고속 매핑하기 위한
       'INTRAWARE.MAPPING_APPR_KEY' 테이블 생성 DDL 및 고속 인덱스 설계
   - sql/06.DOCUMENT_DOCMBR_DIRECT_INSERT.sql (첨부 중복제거 초안):
     * 수신문서(시행문서) 첨부파일이 원기안문서 첨부파일과 동일함에도 물리적으로 중복 생성되는
       스토리지 낭비 문제를 해결하기 위해, 원기안 OBJECTID를 재참조하는 조인 쿼리 설계 (스토리지 50% 절감 방안)
   - sql/07.DUPLICATE_ATTACHMENT_CHECK_AND_FIX.sql:
     * 기존 DB에 이미 중복 생성된 수신문서 첨부(DOCUMENTTYPE=100) 데이터 정밀 검출 및 보정 SQL 작성
